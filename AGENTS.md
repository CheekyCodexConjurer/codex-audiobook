# Codex Audiobook

This repository owns the native-only audiobook workflow.

- Use `$audiobook-codex` for PDF and EPUB mapping, asset inventory, faithful transcription, optional whole-book PT-BR translation, optional `fluid-faithful-ptbr-v1` reading editions, semantic EPUB plus paired non-facsimile PDF export, narrator text, and local Chatterbox PT-BR rendering.
- Keep the public AHK and plugin entry prompts stable and minimal: exactly `$audiobook-codex stage=PHASE-1` and `$audiobook-codex stage=PHASE-2`. The canonical stage defaults, including the per-book `publication_target` flag (`complete`, `fluid`, or `both`), belong in `plugins/audiobook-codex/skills/audiobook-codex/SKILL.md`; role-specific boundaries belong in the agent profiles.
- When a stage behavior, path, default, role route, or validation gate changes, update the internal skill/references/scripts and their validation together. Do not expand or duplicate those options in the AHK bindings, plugin default prompt, or README shortcut lines.
- Use `$voice-calibration` before adding or replacing a local voice reference, TTS engine, or official narrator profile. Calibration artifacts belong under `E:\Pessoal\Library\_voice-calibration-<profile-id>` and must not replace a production profile without immutable evidence, cross-prompt selection, listening review, and a reproducible smoke render.
- Store book artifacts under `E:\Pessoal\Library`, never inside this Git repository. Each book public root is `Nome do Livro - Ano - Autor` and contains `assembly/`, the canonical EPUB/PDF pair, any separately named published fluid EPUB/PDF pair, and the final MP3.
- Use only Codex, native tools, the PDF plugin, optional Computer Use, and local Chatterbox. Do not use browser chat UI, external OCR, external LLMs, or hosted TTS.
- Keep `text/source` and `text/translation/pt-BR` immutable after approval. Fluid reading edits live only under `text/fluid/pt-BR`; speech changes live only under `text/locutor`.
- Translate whole foreign-language books with `faithful-contextual-ptbr-v1`: use chapter and neighboring-scene context, maintain a reviewed glossary, record material ambiguities, and use Codex-native web research only after internal context is insufficient. Research evidence must be recorded, published translations must not supply translation text, and unresolved ambiguity blocks approval.
- Create fluid editions only with `fluid-faithful-ptbr-v1`: select one approved PT-BR base, freeze one whole-book voice and glossary, modernize every genuinely archaic surface form—including inside historical quotations, documentary excerpts, captions, and notes—remove inline parenthetical bibliographic references, omit a paragraph only when it is a proven translation of the immediately preceding paragraph, omit its `Tradução livre` label, preserve auditable ordered base-block coverage, and reject additions, unsupported omissions, semantic drift, residual unreviewed archaisms, or chapter-to-chapter style drift.
- Keep semantic footnotes in the textual editions and EPUB/PDF, but omit their bodies and attached reference markers from `text/locutor` through reviewed `footnote_exclusion` records.
- Keep original source renders and extracted assets immutable. Restored images live only under `assembly/assets/restoration/{candidates,approved}` as reviewed derivatives and never transcription evidence.
- Run writable audiobook delegation only through validated schema `1.0` claim maps, exclusive staging paths, ledger/review shards under `assembly/metadata/work`, independent verification, and deterministic single-owner promotion. Use sliding role pools with backpressure instead of whole-batch waits.
- Use the installed `audiobook-structure`, `audiobook-transcriber`, `audiobook-translator`, `audiobook-editor`, `audiobook-narrator`, and `audiobook-verifier` roles when delegation improves coverage. Select the unsuffixed profile for medium reasoning, or the matching `-low`, `-high`, `-xhigh`, or `-max` profile when the current task warrants it; every variant uses 5.6 Sol.
- Keep Chatterbox inference single-lane unless a separate reproducibility/VRAM benchmark approves concurrency. Overlap chapter assembly/FFmpeg on one bounded CPU worker and mount the book from validated chapter masters.
- Historical promotion manifests and dated calibration reports may retain `E:\Pessoal\e-books` paths only as immutable provenance for earlier decisions; do not rewrite those paths during library migration.
- Validate the smallest affected stage before continuing. Run `scripts\validate.ps1` before declaring repository changes complete.

The generic `$codex-workflows` skill remains installed from `codex-workflows-prompt-pad`. The AHK bindings beginning with `NUM0` are owned here to avoid duplicate prefix-key handling.
